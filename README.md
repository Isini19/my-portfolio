## 📖 About

A personal portfolio website developed to present my professional profile through a clean, modern and responsive interface.

The website is built using vanilla HTML, CSS and JavaScript, with a dark teal and emerald visual theme, interactive elements and responsive layouts.

## ✨ Features

- 🎨 Modern dark theme with teal and emerald accents
- 💫 Typing animation for dynamic text
- 📜 Scroll-reveal animations
- 📊 Animated skill bars
- 🏆 Certificate gallery
- ⏳ Timeline-based layout
- 🧭 Responsive navigation
- 📬 Contact form with submission feedback
- 📱 Responsive design for desktop, tablet and mobile
- ⚡ Lightweight implementation without JavaScript frameworks

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Structure and content |
| CSS3 | Styling, animations and responsive design |
| JavaScript | Interactive functionality and animations |
| Google Fonts | Typography (Playfair Display and Inter) |
| Font Awesome 6 | Icons |
| GitHub Pages | Website hosting |

## 🚀 Getting Started

### View Live

Visit the deployed website:

**[Isini Udara — Personal Portfolio](https://isini19.github.io/my-portfolio/)**

### Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/Isini19/my-portfolio.git
```

**2. Navigate to the project directory**

```bash
cd my-portfolio
```

**3. Open the project**

Open the folder in Visual Studio Code and run `index.html` using the Live Server extension.

No additional package installations or build process are required.

## 🌐 Deployment

The website is hosted using **GitHub Pages**.

Changes pushed to the configured publishing branch are deployed through GitHub Pages.
